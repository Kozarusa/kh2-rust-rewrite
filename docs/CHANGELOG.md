## Shift 7

- **WP-7R (split).** enemy_ai.rs split into enemy_ai, enemy_host and enemy_obj with no behaviour change. Verified by the BDX oracle (54 scripts, 0 failures), the arm-for-arm diff and an identical tt04 host-call table. Open: none.
- **WP-7M (texture regions and animation).** The black rectangles on tt04's roofs were GS CLAMP region modes the app ignored (the map textures have no TEXA or UVSC); the app now crops each image to its region. TEXA sprite and UVSC scroll animation are ported (FUN_00132a80, FUN_00133518) and run on maps, sky and characters; motion range trigger 23 selects TEXA slots, so Sora blinks. Verified by kh2-ee oracle tests (159300 TEXA fields, 24000 UV offsets) and before/after screenshots. Open: linked texture collections, other slot-request callers, the UV offset units (inferred), BOB models are not drawn.

- **WP-7S (game state).** `Progress` resource holds the original's party block (inventory counts, key items, munny, spells, forms, keyblades, abilities, summons) built by the new-game initialiser (FUN_00105638 chain); `KH2_STATE` loads a json state; magic, drive and abilities read it and their env vars still win. The app adds a documented baseline (spare Kingdom Keys, form items, spells 0-3). Verified by the oracle `new_game_block_matches_the_game` (6552 bytes, 466 item counts, give/take sweep, 24 spell rows). Open: story grants, title-menu path, unwired saved bytes.
- **WP-7H (party spec).** `docs/party.md`: member tables per world, spawn and despawn, friend AI, host group 10, combat, HUD, staged plan 1-6. Verified by disc and oracle tests (five). Docs only; no app change. Open: follow-point geometry, style 0 target choice, revive-time record.
- **WP-7D (three more enemies).** M_EX930 (the Dancer, name inferred), N_EX500_BTL and N_EX600_BTL (Struggle opponents, lowest HP 1) run under their own BDX scripts in tt04 groups b_21, b_50 and b_52; enemy runtimes now get the executable's host table; Dusks no longer fault reading their own target record. Verified by the BDX oracle (57 scripts, 12568 host calls, 0 failures), three mode-cycle tests and harness runs with 0 missing calls. Open: the Dancer's player link (force dance), Struggle rules (WP-7E), enemy voices.
- **WP-7A (magic plumbing).** Element bones 0x4001..0x4009 (FUN_0016aa18), spell hit sparks from the hit row, BDX event threads that can start and restart at an event (FUN_0016c500) with a kh2-ee oracle (0 differences), cast voices, MP refill at a form start (FUN_001a0240), the magic lock-on turn rules, and trigger 17's motion-id parameter. The interpreter runs Fire (equal to the hand port, which exposed an inverted element stop/start in the hand port, now fixed); Blizzard, Thunder and Cure stay on the hand port. Verified by the restart oracle, bone tests and harness runs. Open: a test of the hand-port event 21 fix, the live lock-on turn, the trigger-17 parameter rule (inferred), VM host calls for the other spells.
- **WP-FIX-8 (portrait).** User reports: Sora's HUD portrait had blotches and did not change when he was hit. Cause of the blotches: every 8-bit IMGD is drawn in GS CSM1 palette order (0x233588) but the decoder applied that order only to swizzled images; now all 8-bit images do (310 images change, all linear: menu faces, party faces, miss, two item pictures; swizzled ones are byte-identical). Damage face ported from 0x175340 / 0x157e48 / 0x153ee8: a hit shows face group 1 (hurt, red) for 60 frames plus the circle flash 135, then the normal or danger face; knocked-out face group 2. Verified by unit and disc tests, before/after crops and state crops. Open: hit kinds 2 and 3, the KO trigger, first-heal exception, MP-heal event, danger alarm sound; the 60 Hz tick is inferred.
- **WP-7G (areas and events spec).** `docs/events.md`: the area-script interpreter (32 opcodes, triggers), exits and transitions, NPC objects, save and world points, story flags and their side effects, the event player, area music; staged plan E1..E6. kh2-ard now reads activators, walk paths, signals, events and story-flag effects. Verified by disc tests over all Twilight Town area files (373 triggers, 190 events decode). Docs and parser only. Open: talk window opener, save menu opener, event camera keys, skip.
