Verified by three kh2-ee oracles (sprite ST/palette, trail 1792 corners, narrowing 880 corners), before/after screenshots and the user's reference clips. Open: the prize orbs (prize.rs still reads the old unit and mixes blends in one material), two square rainbow sprites in Thunder, the model draw's vertex colour combination, GS SPRITE screen alignment.
